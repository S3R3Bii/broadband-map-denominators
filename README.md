# Check the denominator before claiming broadband coverage gains

A broadband availability percentage depends on the units included in the map as well as the units reported served. A changing map denominator can move that percentage. This study will compare official aggregate summaries across four data dates, separate their arithmetic components and show what those aggregates cannot identify.

**State: protocol before any cohort download.** No empirical finding, new-connection count, investment impact, adoption estimate or live benefit is established. The [protocol](PROTOCOL.md) fixes the public summary files, state-level cohort, source meanings, descriptive comparisons, uncertainty assumptions and release checks. Licensed individual Fabric records are excluded.
